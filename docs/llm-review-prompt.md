### Purposeful Difficulty Framework

**Why some difficult shows work and others don't:**

Shows that work despite being difficult (Unbelievable 4★, Adolescence 4★, Handmaid's Tale 4★, Chernobyl 5★) have:

| Factor | What it means |
|--------|---------------|
| **PURPOSE** | Has something to say, themes, messages ("I love the messages" - The Pitt) |
| **CULTURAL MOMENT** | Feels relevant, discussion-worthy ("I really enjoy watching how a cultural moment unfolds" - Quiz) |
| **PAYOFFS** | Difficulty leads somewhere, rewards investment |
| **MOMENTUM** | Things happen, tension builds |
| **SYSTEMIC VILLAIN** | Critiques systems (Chernobyl → bureaucracy, Unbelievable → system failing victims) not just individual evil |
| **CAMERA SYMPATHY** | Camera is with people fighting against darkness, not just observing suffering |
| **WHO'S SUFFERING** | Historical/witnessed suffering vs intimate/voyeuristic suffering you're forced to watch |

Shows that fail when difficult (Happy Valley 2★, MobLand 2.5★) have:
- Dark for darkness' sake
- Individual evil without broader context (Tommy Lee Royce is just evil)
- No lesson, just suffering
- "Felt pointless"
- You watch suffering happen without agency

**The "cultural moment" test:** Do you want to discuss it afterward? If yes, difficulty was worth it. If you just want to forget it, it was punishing.

**The "viewing context" factor:** Together viewing often has a different purpose (relaxation, connection). A "good" show can be wrong for the context. "We wanted to relax and have a nice night together" - if that's the mood, even quality difficult content may fail.

- Jackson Lamb (Slow Horses) - "Helen just loves Jackson Lamb's one liners so much"
- Ron Swanson (Parks & Rec) - Helen finds him hilarious even if she doesn't love the whole show as Tim does

This archetype can make an otherwise solo-leaning comedy work for together viewing.

**SOLO VS TOGETHER DECISION TREE FOR COMEDY**

```
Is the primary genre Comedy (not Comedy + Crime/Mystery)?
├─ YES: Likely SOLO
│   ├─ Workplace setting? → SOLO (almost certain)
│   ├─ Crude/adult humor? → SOLO (dealbreaker for Helen)
│   ├─ Mockumentary (non-family)? → SOLO
│   └─ Family sitcom format? → TOGETHER (exception)
└─ NO: Check the backbone genre
    ├─ Spy/Mystery/Crime + Comedy → TOGETHER potential
    ├─ Procedural + Comedy → TOGETHER (Helen likes procedurals)
    ├─ Action + Comedy → AVOID entirely
    └─ Sci-Fi + Comedy → SOLO
```

**Quick reference examples:**
- Workplace mockumentary (Abbott Elementary) → Solo
- Family mockumentary (Modern Family) → Together
- Mystery-comedy (Only Murders) → Together
- Seth Rogen comedy (The Studio) → Solo
- Spy-comedy with Jackson Lamb archetype (Slow Horses) → Together

### When to Update Taste Profile & Predictions

The date fields enable tracking when updates are needed:

**Taste profile updates** - Refresh when users have provided new feedback:
```javascript
// Shows rated since a given date (new taste data available)
overlays.filter(o => o.ratedAt && new Date(o.ratedAt) > lastProfileUpdate)

// Shows where user rating differs significantly from prediction (taste correction)
overlays.filter(o => o.rating && o.predictedRating && Math.abs(o.rating - o.predictedRating) >= 1)
```

**Prediction updates** - Re-run when taste profile has evolved:
```javascript
// Shows with stale predictions (rated after prediction was made)
overlays.filter(o => o.rating && o.ratedAt > o.predictionsUpdatedAt)

// Unrated shows that need predictions
overlays.filter(o => !o.rating && !o.predictedRating)
```

**Signs to refresh:**
- New ratings added since last prediction run
- User significantly disagreed with predictions (validates/invalidates patterns)
- New review notes added that reveal preferences
- Watch preference notes updated (solo/together patterns)
