## Prediction Formula

**Base:** `(IMDB / 2) - 0.3★`

**Positive Modifiers:**

- Australian content: +0.5★
- Psychological complexity + jaw-drop potential: +0.5★
- Workplace comedy: +0.5★
- True story: +0.3★
- Limited/complete series: +0.3★
- WWII setting: +0.3★
- 4+ seasons (proven longevity): +0.3★
- Cultural moment / purposeful difficulty: +0.3★

**Negative Modifiers:**

- **Dark character study (not mystery)**: -1.0★ ("Happy Valley effect")
- **Bleak crime without comedy buffer** (together): -0.5★
- Cancelled/unresolved: -0.5★
- Slow-burn/experimental: -0.5★
- Dark without hope: -0.5★
- Style over substance: -0.5★
- New-series volatility (1 season): -0.3★ for 4.5★ predictions (weaker when core preference match — see Pluribus lesson)
- Mystery/crime with critics≫audience gap: caution flag
